# Negative corpus

What the 2c77326 tree learned about the platforms, the market and its own failure modes, carried into v0 so no rebuild learns it twice. Each row names what holds the lesson: a gate (code that refuses), a test (a case that goes red), or a note (a code site or a source when no check can decide it). Source citations point at the 2c77326 tree, archived on its archive branch at takeover; the audit that collected them is section 3 of the re0 slop audit (2026-10-25).

A row is pending until the phase in its Lands column carries its holder; that phase writes the v0 holder and anchor, flips the row to held, and raises the Phase line. `node scripts/check-negative-corpus.mjs` (part of `npm run check`) fails when a held row's holder file is missing or lacks its anchor, when a row of a phase at or before the Phase line is still pending, or when a row breaks the table shape.
